# Luma

Luma is an AI-powered personal life assistant designed to improve productivity through intelligent memory management and personalized interactions. The platform combines conversational AI, structured memory, and task-oriented workflows to help users stay organized, remember important context, and make better daily decisions.

## Overview

Luma is built to act as a smart companion for everyday life. It can help with:

- remembering important personal and professional context
- organizing conversations and task-related information
- providing tailored support for planning and decision-making
- maintaining continuity across sessions through memory-aware interactions

The project is designed as a full-stack application with a modern frontend experience and a backend powered by Python and FastAPI-style architecture.

## Core Goals

- Deliver a personalized AI assistant experience
- Manage long-term context through intelligent memory routing
- Support productivity-focused use cases such as planning, reminders, and daily assistance
- Provide a clean and scalable architecture for future AI features

## Project Structure

- Backend: Python-based API and service layer for authentication, chat, memory, and AI workflows
- Frontend: React Native / Expo application for a mobile-friendly experience
- Shared project setup: root workspace configuration and documentation

## Tech Stack

### Frontend
- React Native
- Expo Router
- NativeWind
- TypeScript

### Backend
- Python
- FastAPI-style application structure
- SQLAlchemy-style database models and services
- Authentication, chat, and memory modules

## Features

### Intelligent memory management
Luma is designed to retain relevant context and route information efficiently so conversations remain coherent and personalized over time.

### Personalized interactions
The assistant aims to adapt to user preferences and recurring needs, making daily support more useful and relevant.

### Productivity-focused workflows
The platform is built to support task-oriented assistance, planning, and decision support in a streamlined experience.

## Getting Started

### Prerequisites
- Node.js and npm
- Python 3.10+
- Expo CLI (for the frontend)

### Backend setup
1. Navigate to the backend folder.
2. Create and activate a virtual environment.
3. Install dependencies if required.
4. Run the application server.

### Frontend setup
1. Navigate to the frontend folder.
2. Install dependencies with npm.
3. Start the Expo development server.

## Development Notes

This repository is organized to support both the AI service layer and the user-facing mobile application. As the project evolves, the architecture can be extended with additional modules for memory optimization, agent workflows, and richer personalization.
